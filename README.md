# CodeAlpha_StockPortfolioTracker
A Stock Portfolio Tracker is a Python application that allows users to manage and monitor their stock investments. Users can add stocks to their portfolio, enter the quantity and purchase price, and calculate the total investment value

##  About the Project

The **Stock Portfolio Tracker** is a simple Python-based application that calculates the total investment value of a user's stock portfolio.
The program uses a predefined list of stock prices stored in a Python dictionary. The user enters a stock name and the number of shares they own. The program then calculates the investment value for each stock and adds them together to display the total portfolio value.

## Concepts used

This project was developed as a beginner-friendly Python project to practice dictionaries, user input, loops, conditional statements, and basic arithmetic operations.

##  Features

- Calculate the investment value of stocks.
- Allow users to enter stock names and quantities.
- Use a dictionary to store predefined stock prices.
- Calculate the total portfolio investment.
- Provide a simple and interactive command-line interface.
